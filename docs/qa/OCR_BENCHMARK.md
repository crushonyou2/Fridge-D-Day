# OCR 품질 벤치마크

이 문서는 오늘도 신선의 OCR 품질을 실제 라벨 사진으로 반복 측정하기 위한 기준이다. 아직 측정하지 않은 값은 성과로 공개하지 않는다.

## 측정 단위

- 1행은 사진 1장이다.
- 원본 사진은 개인정보와 제품 정보가 포함될 수 있으므로 저장소에 커밋하지 않는다.
- `sample_id`만으로 별도 로컬 원본과 연결한다.
- 앱이 제안한 날짜를 수정 없이 저장할 수 있으면 `exact_match=true`로 기록한다.

## 데이터 구성 목표

- 총 200장 이상
- 조명: 밝음, 어두움, 반사
- 방향: 정방향, 90도, 기울어짐
- 표기: YYYY.MM.DD, YY.MM.DD, MM.DD, 숫자 연속
- 재질: 종이, 비닐, 캔, 병뚜껑
- 실패 사례도 삭제하지 않고 유지

## 핵심 지표

- OCR 날짜 정확 일치율 = 정확히 맞춘 사진 / 전체 사진
- 날짜 후보 탐지율 = 날짜 후보를 반환한 사진 / 전체 사진
- 수동 수정률 = 사용자가 날짜를 수정한 사진 / 전체 사진
- 환경별 정확 일치율: 조명·방향·재질별 분리

측정값은 `ocr-benchmark.csv`에 기록하고, 릴리스마다 같은 표본으로 회귀 여부를 확인한다.
